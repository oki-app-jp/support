# Oki サポート

Okiの紹介・ヘルプ・プライバシーポリシー・利用条件の公開サイトです。

- [紹介](https://oki-app-jp.github.io/support/)
- [ヘルプ・お問い合わせ](https://oki-app-jp.github.io/support/support.html)
- [プライバシーポリシー](https://oki-app-jp.github.io/support/privacy.html)
- [利用条件](https://oki-app-jp.github.io/support/terms.html)

App Storeでの公開準備中です。問い合わせ先：yuya.app.support@gmail.com。

JavaScript、外部フォント、広告、アクセス解析、問い合わせフォームは使用していません。アプリ本体のコードや署名情報は含みません。

## 管理・公開

このリポジトリでサポートサイトをアプリ本体とは独立して管理します。HTML・CSS・画像はこのリポジトリで編集し、`main`へプッシュするとGitHub Pagesがルートから公開します。

```sh
git clone https://github.com/oki-app-jp/support.git oki-jp-support
cd oki-jp-support
```

アプリ本体：[YUYA-hoge/oki](https://github.com/YUYA-hoge/oki)。サポートサイトの公開先は上記のURLを使用します。
